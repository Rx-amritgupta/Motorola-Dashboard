# 📱 Mobile Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an **interactive Mobile Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides a comprehensive view of mobile sales performance, helping analyze sales trends, transactions, customer ratings, payment methods, mobile models, brands, and geographical sales distribution.

This project was created as part of my learning journey with **Skill Course by Satish Dhawale Sir**, where I learned practical concepts of Power BI, data visualization, dashboard design, and data analysis.

---

## 🎯 Objectives

The main objective of this project is to transform mobile sales data into meaningful and interactive visual insights.

The dashboard helps answer questions such as:

- What are the total sales and quantity sold?
- How are sales performing month by month?
- Which mobile models have higher sales?
- Which cities generate more sales?
- What payment methods are most commonly used?
- How are customers rating their purchases?
- Which days of the week have higher sales?
- How do different mobile brands and models perform?

## 📈 Dashboard Features

### 1. Monthly Sales Analysis
A line chart shows the **total sales trend across different months**, making it easy to identify increases and decreases in sales performance.

### 2. Customer Ratings
The dashboard provides a breakdown of customer ratings from **1 to 5**, allowing analysis of customer satisfaction.

### 3. Sales by City
A geographical visualization displays sales distribution across different cities.

### 4. Transaction & Payment Method
A pie chart compares different payment methods, including:

- UPI
- Debit Card
- Credit Card
- Cash

### 5. Mobile Model Analysis
A detailed table provides insights into:

- Mobile Model
- Units Sold
- Price
- Customer Ratings

### 6. Sales by Day Name
The dashboard analyzes sales performance across different days of the week.

### 7. Interactive Filters
Users can dynamically filter the dashboard using:

- 📱 Mobile Model
- 🏷️ Brand
- 📅 Date
- ⭐ Customer Rating
- 📆 Month
